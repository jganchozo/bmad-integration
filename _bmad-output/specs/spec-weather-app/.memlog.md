- (direction) Build a small weather application for a user to check a city's current conditions.
- (capability) CAP-1: User can search for a city and identify the desired location.
- (capability) CAP-2: User can view current temperature, weather condition, and wind speed for the chosen city.
- (constraint) Weather data comes from Open-Meteo.
- (constraint) No user authentication.
- (constraint) No paid APIs.
- (constraint) No multi-day forecast in v1.
- (note) Open-Meteo provides geocoding and current weather variables; its hosted free API requires noncommercial use and data attribution per its published terms.
- (decision) Use express mode: derive a concise spec from the supplied request.
- (decision) The application is for noncommercial use, so Open-Meteo's free hosted API is eligible subject to its terms and attribution.
- (assumption) City searches with multiple matches will let the user distinguish and choose a location by region and country.
- (assumption) A missing city result or unavailable weather response will show a clear message instead of invented weather values.
- (assumption) Until units are confirmed, display Celsius for temperature and km/h for wind speed, matching Open-Meteo defaults.
